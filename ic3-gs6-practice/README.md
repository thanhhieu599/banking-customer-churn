# Phòng Luyện IC3 GS6 – Level 2

Trang web tự luyện thi IC3 Digital Literacy GS6 Level 2, mô phỏng giao diện phần mềm thi trên máy.

- Mở `index.html` bằng trình duyệt (Chrome/Edge), không cần cài đặt hay máy chủ.
- `app.html` là bản nguồn dùng để xuất bản dạng Artifact; `index.html` là bản đầy đủ để mở trực tiếp.
- Thêm câu hỏi: sửa mảng `BANK` trong thẻ `<script>` (dạng: single, multi, yesno, match, hotspot).
