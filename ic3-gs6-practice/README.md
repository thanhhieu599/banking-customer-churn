# IC3 GS6 Spark Level 2 – Phòng luyện thi

Trang web tự luyện thi IC3 Digital Literacy GS6 Spark Level 2, mô phỏng giao diện phần mềm thi trên máy.

- Mở `index.html` bằng trình duyệt (Chrome/Edge), không cần cài đặt hay máy chủ.
- `app.html` là bản nguồn dùng để xuất bản dạng Artifact; `index.html` là bản đầy đủ để mở trực tiếp.
- Ngân hàng 100 câu theo 7 lĩnh vực GS6; 5 dạng câu: single, multi, yesno, match (ghép cặp/sắp xếp), hotspot.
- Thêm câu hỏi: sửa mảng `BANK` trong thẻ `<script>`.
